This entry is a small program that writes one short text to intrigue the AI judge. A lighthouse keeper left one lamp burning in the tower every night for forty years and never wrote down why. His logbook ends mid-sentence, on a Tuesday — the question stays open, and the sentence itself stops before the answer.

## How to run

```sh
python3 main.py
```

It writes the text to `/output/entry.txt`.
